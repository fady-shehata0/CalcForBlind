# Advanced Calculator

A bilingual calculator built with Python and wxPython.

## Features
- English and Arabic interface
- Light, dark, and high-contrast themes
- Color-blind safe palette
- Font scaling
- Basic math operations and functions
- Memory operations
- Accessibility support
- Calculation history
- Settings persistence
- Windows EXE build support

## Run

```powershell
cd "C:\Users\FadyCenter\Desktop\calc"
python -m pip install -r requirements.txt
python calculator.py
```

## Build EXE

```powershell
python build_exe.py
```

## Notes
The project saves settings in `calculator_settings.json`.
